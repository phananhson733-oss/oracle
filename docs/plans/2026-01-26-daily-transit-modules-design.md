# 今日运势技术模块视觉优化设计

## 目标
- 保持“纸感极简”风格并与现有今日运势页面一致
- 统一顶部技术模块的视觉层级与节奏
- 强化可读性与对比度，避免信息噪音
- 保留相位矩阵完整网格直显

## 范围
- 今日行运星象
- 星象详情：相位矩阵
- 行运行星
- 行运小行星
- 宫主星

## 非目标
- 不改动业务数据结构与接口
- 不替换星盘组件实现逻辑
- 不新增复杂交互或动效

## 结构方案
- 统一技术卡结构：`technical-head`、`technical-body`、`technical-footnote`
- 头部包含标题、短说明与“查看详情”按钮
- 内容区承载图例、星盘、矩阵或表格
- 脚注用于盘面内外环说明或数据口径提示

## 视觉规范
- 颜色与对比度遵循 `COLOR_SYSTEM_GUIDE.md`
- 背景使用 `paper-*` 纸感层级，避免纯白/纯黑
- 标题与正文使用 `paper-900` / `paper-600`，弱化文字 `paper-400`
- 相位矩阵：表头 `paper-200`，有相位单元格使用淡底 + 彩色字
- 表格：扁平化分隔，去除嵌套卡片和左侧色条
- 统一小号大写风格表头与紧凑字距

## 模块细化
- 今日行运星象：图例下沉到头部下方一行，星盘容器使用柔和底板与圆角
- 相位矩阵：保留完整网格，标签区压缩字级但保证可读
- 行运行星/小行星：表头轻量化，行内容对齐优化
- 宫主星：飞入宫位使用浅底胶囊，宫位数字突出但不抢眼

## 交互与动效
- 保留现有页面进入动效与轻微交互
- 不新增复杂动画，避免影响性能

## 风险与注意
- 确保 Unicode 占星符号与底板对比度满足 AA
- 小程序端布局需验证不同屏宽下表格不会溢出
