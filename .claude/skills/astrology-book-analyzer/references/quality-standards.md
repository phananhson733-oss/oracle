# 写作质量标准与检查清单 | Writing Quality Standards and Checklist

本文档定义报告的质量标准和完整的检查清单。

---

## 写作质量标准 | Writing Quality Standards

### 1. 深度标准 | Depth Standard

**[Unacceptable] 不合格:**
- 仅仅复述书中内容,没有独立分析
- 只列举概念,不深入解释
- 没有揭示作者的底层逻辑

**[Acceptable] 合格:**
- 每个章节都有独立的分析视角
- 概念解释有深度,揭示"为什么"
- 批判性评价有理有据

**[Excellent] 优秀:**
- 揭示作者未明说的隐含假设
- 将书中内容置于占星学史脉络中
- 提供超越原书的延伸思考

### 2. 易读性标准 | Readability Standard

**[Unacceptable] 不合格:**
- 专业术语没有通俗解释
- 大段理论堆砌,没有分段
- 缺少案例和比喻

**[Acceptable] 合格:**
- 专业术语配通俗解释
- 段落长度适中,结构清晰
- 有适当的案例或比喻

**[Excellent] 优秀:**
- 通俗解释生动准确
- 使用图表、流程图辅助说明
- 复杂概念用多个角度解释

### 3. 实用性标准 | Practicality Standard

**[Unacceptable] 不合格:**
- 理论与实践脱节
- 没有可操作的学习建议
- 缺少"如何应用"的指导

**[Acceptable] 合格:**
- 理论连接实践应用
- 提供分阶段学习计划
- 给出立即行动建议

**[Excellent] 优秀:**
- 每个理论都有实践转化方案
- 学习计划有明确检验标准
- 解答读者可能遇到的实际困惑

## 写作风格指南 | Writing Style Guide

### 语言风格 | Language Style

**中文报告 | Chinese Report:**
- 使用清晰、准确的现代汉语
- 专业术语首次出现时附英文
- 避免过度学术化的表述
- 适当使用"你"/"读者"等称呼,增加亲切感
- **禁止使用Emoji图标**

**英文报告 | English Report:**
- Use clear, professional English
- Avoid overly academic jargon
- Use "you" when appropriate for engagement
- Maintain consistent terminology
- **No Emojis allowed**

### 结构风格 | Structural Style

- 使用清晰的标题层级
- 段落长度3-5句为宜
- 重要内容用加粗或框框标记
- 合理使用列表和表格
- 适当使用分隔线区分章节
- 长段落中使用小标题

### 术语使用 | Terminology Use

**一致性 Consistency:**
- 同一术语在全文保持一致翻译
- 建立术语对照表

**本土化 Localization:**
- 中文报告可适当使用中国传统术语类比
- 但必须同时提供英文原词

**定义明确 Clear Definitions:**
- 关键术语首次出现时给定义
- 区分古典术语和现代用法

## 质量控制清单 | Quality Control Checklist

### 内容完整性检查 | Content Completeness Check

- [ ] 六大模块全部完成
- [ ] 字数达到约10000字(允许±10%浮动)
- [ ] 根据书籍类型调整了字数分配
- [ ] 包含5-8条经典金句摘录与解读
- [ ] 包含3-5段经典段落引用与深度解析
- [ ] 包含全书核心思想一句话提炼
- [ ] 包含3-5个核心概念的通俗解释和生活比喻
- [ ] 包含底层逻辑分析(核心问题+底层假设+论证主线)
- [ ] 包含分阶段学习计划(4个阶段,每阶段有目标、行动、检验标准)
- [ ] 包含立即行动建议(5条具体可执行)

### 深度检查 | Depth Check

- [ ] 每个概念都有通俗解释,不是仅仅复述
- [ ] 核心章节精读揭示了作者的深层逻辑
- [ ] 批判性评价有理有据,不是空泛赞美或贬低
- [ ] 底层逻辑分析揭示了作者的核心问题和假设
- [ ] 金句解读有深度,不是简单复述

### 易读性检查 | Readability Check

- [ ] 专业术语都配通俗解释
- [ ] 有生活比喻帮助理解抽象概念
- [ ] 段落长度适中,没有超长段落
- [ ] 使用了小标题、列表、表格等提升可读性
- [ ] 复杂技法有流程图或步骤分解

### 实用性检查 | Practicality Check

- [ ] 理论都连接了实践应用
- [ ] 技法有清晰的操作步骤
- [ ] 学习计划可操作,有明确检验标准
- [ ] 立即行动建议具体可执行
- [ ] 解答了读者可能遇到的实际困惑

### 准确性检查 | Accuracy Check

- [ ] 书名、作者名拼写正确
- [ ] 术语定义准确
- [ ] 金句和段落引用(如为模拟引用需标注)
- [ ] 历史信息准确

### 格式检查 | Format Check

- [ ] 标题层级清晰
- [ ] 表格格式正确
- [ ] 无明显排版错误
- [ ] 中英文报告格式一致
- [ ] **已移除所有Emoji图标**

## 常见问题与解决方案 | Common Issues and Solutions

### 问题1: 术语解释不够通俗

**症状 Symptoms:**
- 读者反馈看不懂
- 使用了过多专业术语
- 解释仍然很学术化

**解决方案 Solutions:**
1. 使用"就像..."的比喻句式
2. 举日常生活中的具体例子
3. 用"换句话说"重新表述
4. 请非专业人士试读并反馈

### 问题2: 理论与实践脱节

**症状 Symptoms:**
- 大量理论阐述但缺少应用指导
- 读者不知道如何使用书中知识
- 案例分析缺失或不够详细

**解决方案 Solutions:**
1. 每个理论后添加"实践应用"小节
2. 提供具体的操作步骤
3. 增加案例示范
4. 添加"常见错误"提醒

### 问题3: 批判性分析不够客观

**症状 Symptoms:**
- 过度赞美或贬低
- 没有指出局限性
- 缺少与其他观点的对比

**解决方案 Solutions:**
1. 使用"优势与局限"框架
2. 明确适用范围和边界
3. 引入其他作者的不同观点
4. 保持中立客观的语气

### 问题4: 学习计划不够具体

**症状 Symptoms:**
- 建议过于笼统
- 缺少检验标准
- 读者不知道从何开始

**解决方案 Solutions:**
1. 分阶段设计(4个阶段)
2. 每阶段明确目标、行动、检验标准
3. 提供"立即行动"建议
4. 给出具体的时间建议(如"本周完成")

## 报告提交前最终检查 | Final Check Before Submission

### 快速自检问题 | Quick Self-Check Questions

1. **深度**: 我是否揭示了作者的底层逻辑和隐含假设?
2. **易读性**: 非专业读者能否理解所有专业术语?
3. **实用性**: 读者能否根据报告制定学习计划并开始行动?
4. **完整性**: 是否包含了所有必需的模块和要素?
5. **准确性**: 书名、作者名、术语定义是否准确?

### 同行评审标准 | Peer Review Standards

如果有条件,请同行评审者检查:
- 分析深度是否足够
- 通俗解释是否准确易懂
- 实践建议是否可操作
- 批判性评价是否客观
- 整体结构是否清晰
