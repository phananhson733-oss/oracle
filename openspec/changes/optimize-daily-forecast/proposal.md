# Change: 优化今日运势内容结构与AI解读模块

## Why

当前日运页面内容组织较为简单,缺乏层次感和深度。用户无法快速获取关键信息，也缺少针对不同维度（事业/财运/爱情/健康）的细分评分和建议。此外，时间窗口、宜忌建议等实用功能未充分展现，本周趋势和相位矩阵等专业内容缺乏系统化解读。需要重构日运内容结构，引入多层次AI解读，提升用户体验和专业度。

## What Changes

### 1. 内容排版优化
重新组织日运页面模块顺序，采用渐进式信息呈现：
- **快速浏览层**：
  - 今日运势概览卡片（总分、幸运元素、总结）
  - 四维度简要评分（事业/财运/爱情/健康）
  - 今日宜忌建议（DO/DON'T）
  - 关键时间窗口（上午/下午/晚上能量标注）
- **深度解读层**：
  - 四维度详细解读（点击展开）
  - 今日星象深度分析
  - 行运星盘可视化
  - 相位矩阵分析
- **趋势预览层**：
  - 本周运势趋势

### 2. AI 解读模块重构
新增 7 个结构化 AI 提示词模块：

#### 2.1 今日运势概览
- **输入**：本命太阳/月亮/上升、今日行运行星位置、重要相位
- **输出**：运势总分（0-100）、幸运色/数字/方位、今日总结（2-3句）
- **逻辑**：评分基于相位和谐度、幸运元素从主导行星推导

#### 2.2 四维度评分系统
- **维度定义**：
  - 事业运（Career）：10宫、土星、太阳影响
  - 财运（Wealth）：2宫、8宫、木星、金星影响
  - 爱情运（Love）：5宫、7宫、金星、火星影响
  - 健康运（Health）：6宫、12宫、月亮影响
- **评分算法**：检查相关宫位行运 → 检查相关行星状态 → 检查与本命相位
- **输出**：每个维度 0-100 分 + 简要说明

#### 2.3 四维度详细解读（按需加载）
- **输入**：用户本命相关宫位/行星、今日行运详情、相位强度
- **输出**：当前影响分析（150-200字）、具体建议（3-5条）、关键相位解读（2-3个）

#### 2.4 今日宜忌建议
- **输入**：主要和谐相位、主要挑战相位、月亮状态、水星状态
- **输出**：
  - 宜做（DO）：标题 + 3-4条建议
  - 忌做（DON'T）：标题 + 3-4条建议

#### 2.5 关键时间窗口
- **时段划分**：上午（6-12）、下午（12-18）、晚上（18-24）
- **能量标签**：积极期 / 平稳期 / 放松期 / 挑战期（不使用 emoji）
- **输出**：每时段包含能量评估、描述、适合做什么、避免做什么

#### 2.6 今日星象深度分析
- **输出结构**：
  - 今日星象概览（100字）
  - 关键行运分析（2-3个，每个150-200字）
  - 本命盘激活点列表
  - 建议与洞察（3-5条）

#### 2.7 本周运势趋势
- **输入**：本周每日主要相位、行星换座事件、月亮运行轨迹
- **输出**：
  - 每日运势评分（0-100）
  - 关键日期标注（重要相位 / 月亮换座 / 行星换座 / 挑战日，不使用 emoji）
  - 本周总体走向（150字）
  - 最佳行动日和休息日

#### 2.8 相位矩阵解读
- **输入**：完整相位列表（行运 vs 本命）
- **输出**：
  - 整体模式识别（和谐/挑战主导、特殊格局）
  - 前三重要相位详细解读（每个100字）
  - 能量主题总结

### 3. UI 设计规范
- 遵循 `COLOR_SYSTEM_GUIDE.md` 的 paper/space 体系与语义色规则
- 使用卡片化布局，层次分明
- 四维度评分采用环形进度条可视化
- 时间窗口使用“文字 + 色点/PNG/SVG/Unicode”标识能量状态（禁用 emoji 与星座 Unicode）
- 可展开/折叠模块采用渐进式加载

### 4. 技术实现要点
- **后端 API 扩展**：
  - 扩展 `/daily-forecast` 接口，返回完整结构化数据
  - 新增四维度评分计算逻辑
  - 新增时间窗口能量计算
  - 新增本周趋势数据
- **前端组件**：
  - 重构 `daily.wxml` 模板结构
  - 新增四维度评分组件
  - 新增时间窗口组件
  - 新增可展开详情组件
- **AI 提示词管理**：
  - 在后端统一管理 7 个提示词模板
  - 支持动态参数替换
  - 仅输出中文（中国大陆用户）

## Impact

- **Affected specs**:
  - `provide-daily-forecast`（重大修改）
  - `backend-data-services`（需扩展 API）
- **Affected code**:
  - `miniprogram/pages/daily/daily.js` - 数据处理逻辑重构
  - `miniprogram/pages/daily/daily.wxml` - 模板结构重构
  - `miniprogram/pages/daily/daily.wxss` - 样式重构
  - `backend/` - 新增 AI 解读逻辑和四维度计算
- **Breaking changes**: 无，API 向后兼容（扩展字段）
- **UI 规范符合性**: 需使用 frontend-design skill 设计卡片组件，严格遵循 COLOR_SYSTEM_GUIDE.md

## Dependencies

- 需要先完成 AI 提示词的测试和优化
- 需要 UI 设计审查通过
- 需要后端 API 开发完成

## Success Criteria

1. 用户能在 3 秒内快速浏览今日关键信息（总分、四维度、宜忌）
2. 四维度评分准确反映当日星象对各生活领域的影响
3. 时间窗口建议与实际行运时刻对应
4. 本周趋势帮助用户提前规划
5. 相位矩阵解读专业且易懂
6. UI 符合品牌设计规范，视觉层次清晰
