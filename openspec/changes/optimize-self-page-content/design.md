# Design: 本我页面内容优化

## 1. 模块排序设计

### 1.1 排序原则

采用"渐进式深入"的信息架构：

```
┌─────────────────────────────────────────┐
│  第一层：概览（本命盘 + Big3）           │
│  → 快速了解核心特质                      │
├─────────────────────────────────────────┤
│  第二层：心理维度（12维解读）            │
│  → 多角度自我认知                        │
├─────────────────────────────────────────┤
│  第三层：深度解析（6大维度）             │
│  → 人生各领域详细指导                    │
├─────────────────────────────────────────┤
│  第四层：专业附录（技术数据）            │
│  → 供进阶用户参考                        │
├─────────────────────────────────────────┤
│  第五层：付费内容（流年运势）            │
│  → 进阶付费服务                          │
└─────────────────────────────────────────┘
```

### 1.2 排序理由

| 位置 | 模块 | 理由 |
|------|------|------|
| 1 | 本命盘预览 | 视觉锚点，建立占星语境 |
| 2 | Big3 解读 | 核心三要素，快速建立认知 |
| 3 | 12维心理解读 | 心理学视角，实用性强，用户关注度高 |
| 4 | 6大维度深度解析 | 人生各领域详细指导，内容丰富 |
| 5 | 专业星象数据附录 | 技术性内容，供进阶用户参考 |
| 6 | 2026流年运势 | 付费内容放最后，不打断免费内容阅读流程 |

## 2. 提示词系统设计

### 2.1 设计原则

#### 文化适配原则
- **使用**：二十四节气、诗词、成语、中国哲学概念
- **避免**：能量、频率、宇宙、灵魂伴侣等西方新时代术语

#### 语言风格原则
- **使用**："你会发现..."、"很多时候..."、"你可能自己都没意识到..."
- **避免**："应该"、"必须"、"你很特别"、"命中注定"

#### 内容结构原则
- 每段都要有具体画面感
- 正面特质 + 可能的挑战
- 给出可执行的建议
- 赋能而非评判

### 2.2 Big3 解读提示词规范

#### 太阳星座提示词

```
【输入信息】
- 太阳星座：{sun_sign}
- 太阳所在宫位：{sun_house}
- 用户性别：{gender}（可选）

【输出要求】
1. 字数：180-220字
2. 结构：
   - 开场比喻（1句话，用中国文化意象）
   - 核心性格特质（3-4句）
   - 具体生活场景1（工作/学习相关）
   - 具体生活场景2（人际关系相关）
   - 金句总结（1句话）

3. 必须包含：
   - 太阳在该宫位的特殊表现
   - 正面特质 + 可能的挑战
   - 给人的第一印象 vs 内在驱动力
   - 成就感来源

4. 禁忌：
   ❌ 不要说"你很特别/与众不同"
   ❌ 不要使用"宇宙"、"能量场"等玄学词汇
   ❌ 不要给出模糊的建议（如"做真实的自己"）
```

#### 月亮星座提示词

```
【输入信息】
- 月亮星座：{moon_sign}
- 月亮所在宫位：{moon_house}
- 月亮相位：{moon_aspects}（如有重要相位）

【输出要求】
1. 字数：180-220字
2. 核心主题：
   - 情绪反应模式
   - 安全感来源
   - 内在需求（可能连自己都未察觉）
   - 在亲密关系中的表现
   - 童年家庭环境的影响印记

3. 结构：
   - 开场：用"内心深处"、"无人时"等词切入私密感
   - 情绪模式描述（举1个具体场景）
   - 安全感来源（说明什么让你踏实）
   - 在亲密关系中的需求
   - 成长建议（温柔而具体）

4. 语言特点：
   - 比太阳星座更柔软、更私密
   - 多用"你可能自己都没意识到..."
   - 涉及童年时用"小时候的你..."
   - 避免指责父母（用"家庭环境"代替）
```

#### 上升星座提示词

```
【输入信息】
- 上升星座：{rising_sign}
- 上升度数：{rising_degree}（可选）
- 第一宫内行星：{first_house_planets}（如有）

【输出要求】
1. 字数：180-220字
2. 核心主题：
   - 给人的第一印象（3秒钟的印象）
   - 面对世界的方式/人生态度
   - 外在形象与穿衣风格倾向
   - 今生要学习的人生课题
   - 与太阳/月亮的互动（如差异明显）

3. 结构：
   - 开场：描述别人眼中的你
   - 第一印象 vs 真实自我（如有差异）
   - 应对陌生环境的方式
   - 人生课题（用"这辈子..."开头）
   - 成长方向（具体可行）

4. 特殊说明：
   - 上升代表"人生剧本"，要有使命感
   - 如果上升与太阳/月亮反差大，要说明"面具"现象
   - 涉及外貌时要谨慎，用"气质"替代"长相"
```

### 2.3 12维心理解读提示词规范

#### 通用框架

```
【输入信息】
- 完整本命盘数据
- 当前解读维度：{dimension_name}

【输出要求】
1. 字数：200-250字
2. 结构（严格遵守）：
   【核心模式】（60-80字）
   - 用一个比喻开场
   - 说明这个维度的核心特征

   【具体表现】（80-100字）
   - 场景1：日常生活中的体现
   - 场景2：压力情境下的反应
   - 附加说明：可能连自己都没意识到的细节

   【潜在挑战】（40-50字）
   - 这个模式可能带来的困扰
   - 用"但要注意..."引导

   【成长建议】（40-50字）
   - 2条具体可执行的建议
   - 避免"做自己"、"保持平衡"等空话
```

#### 12个维度的分析重点

| 维度 | 重点行星 | 解读方向 |
|------|----------|----------|
| 情绪模式 | 月亮、海王星、第4/8/12宫 | 情绪来得快还是慢、如何消化情绪 |
| 人际边界 | 月亮、土星、第7/11宫 | 多远的距离让你舒服、如何拒绝别人 |
| 安全感来源 | 月亮、土星、第2/4宫 | 什么让你踏实、害怕失去什么 |
| 表达方式 | 水星、第3宫、上升 | 说话风格、倾听vs表达比例 |
| 决策模式 | 水星、太阳、土星 | 理性vs直觉、决策速度 |
| 压力应对 | 火星、土星、第6/12宫 | 压力源、身体反应、恢复方式 |
| 爱的语言 | 金星、火星、第5/7宫 | 如何表达爱、期待被怎样对待 |
| 金钱观 | 金星、木星、第2/8宫 | 花钱风格、理财态度 |
| 成长课题 | 土星、南北交点、第12宫 | 今生要克服的模式 |
| 创造力源泉 | 太阳、海王星、第5宫 | 灵感来源、创作冲动 |
| 亲密关系模式 | 金星、月亮、火星、第7/8宫 | 吸引什么样的人、关系中的角色 |
| 社会角色 | 太阳、土星、第10宫 | 在集体中的定位、对成功的定义 |

## 5. 决策记录

### 5.1 为什么将流年运势放最后？

- 付费内容不应打断免费内容的阅读流程
- 用户在充分了解本命盘后，更有动力购买进阶内容
- 符合"先价值后变现"的产品策略

### 5.2 为什么 12维心理解读提前？

- 心理学视角更贴近现代用户需求
- 12个维度覆盖面广，实用性强
- 作为 Big3 的延伸，形成完整的自我认知链路

### 5.3 为什么使用结构化提示词？

- 确保输出格式一致，便于前端渲染
- 控制字数，避免内容过长或过短
- 便于后续迭代和 A/B 测试
