# Change: 优化本我页面内容排版与提示词系统

## Why

当前"本我"（探索自我）页面存在以下问题：

1. **模块排序不合理**：付费内容（2026流年运势）位置过于靠前，打断用户阅读流程；12维心理解读作为核心内容却被放在较后位置。
2. **提示词缺乏本土化**：现有 AI 解读提示词未针对中国大陆用户优化，缺乏文化共鸣和实用性。
3. **弹窗交互体验不足**：点击"查看详情"后的弹窗卡片设计简陋，缺乏层次感和视觉吸引力。

## What Changes

### 1. 模块排布顺序调整

**调整前**：
1. 本命盘预览
2. Big3 解读
3. 2026年流年运势（付费）
4. 心理维度分析（12维）
5. 深度解析（6大维度）
6. 专业技术附录

**调整后**：
1. 本命盘预览（保持）
2. Big3 解读（保持）
3. 12维心理解读（提前）
4. 深度解析6大维度
5. 专业星象数据附录
6. 2026年流年运势（付费）← 移至最后，作为"进阶付费内容"

### 2. 提示词系统优化

为每个模块设计完整的 AI 提示词，针对中国大陆用户优化：

#### 2.1 Big3 解读提示词
- **太阳星座**：180-220字，结合中国文化意象（二十四节气、诗词、成语）
- **月亮星座**：180-220字，聚焦情绪模式与安全感来源
- **上升星座**：180-220字，描述外在呈现与人生课题

#### 2.2 12维心理解读提示词
每个维度 200-250字，结构化输出：
- 【核心模式】60-80字
- 【具体表现】80-100字
- 【潜在挑战】40-50字
- 【成长建议】40-50字

12个维度：情绪模式、人际边界、安全感来源、表达方式、决策模式、压力应对、爱的语言、金钱观、成长课题、创造力源泉、亲密关系模式、社会角色

#### 2.3 深度解析6大维度提示词
每个维度 450-550字，包含：
- **事业发展**：职业DNA、适合赛道、工作风格、职场关系、发展时间表
- **财富金钱**：财富体质、赚钱方式、消费画像、理财性格、增长攻略
- **爱情婚姻**：爱情人格、择偶雷达、恋爱模式、关系挑战、长期指南
- **人际关系**：社交人设、朋友圈图谱、人际边界、冲突策略、人脉经营
- **健康养生**：体质档案、健康易感区、运动处方、饮食作息、生命周期规划
- **自我成长**：灵魂剧本、旧模式告别、待开发宝藏、转折时刻表、实现路线图

#### 2.4 专业星象数据附录提示词
- **元素矩阵**：表格 + 一句话解读（50字内）
- **相位矩阵**：8-10个重要相位，每个30字内说明
- **行星信息**：表格 + 逆行说明 + 特殊配置
- **小行星信息**：4颗主要小行星解读
- **宫主星信息**：宫主星流转图 + 重点解读

### 3. 弹窗卡片 UI 优化

使用 `frontend-design` skill 设计高质量弹窗卡片：
- 遵循 COLOR_SYSTEM_GUIDE.md 规范
- 深色主题（space-950 背景）
- 金色强调色（accent）
- 充足内边距（p-6/p-8）
- 统一过渡动画（transition-all duration-300）
- 避免多层卡片嵌套

## Design Principles

### 提示词设计原则
1. **文化适配**：使用中国文化意象（二十四节气、诗词、成语），避免西方占星术语（能量、频率、宇宙）
2. **语言风格**：像朋友聊天，多用"你会发现..."、"很多时候..."，避免说教
3. **具体场景**：每段都要有具体画面感，给出可执行建议
4. **赋能导向**：正面特质+挑战，强调选择而非命运

### UI 设计原则
1. **简洁极简**：遵循 COLOR_SYSTEM_GUIDE.md 核心美学
2. **空白呼吸**：卡片内边距 p-6/p-8，元素间隙 gap-4/gap-6
3. **禁止 Emoji**：使用 PNG/SVG 资源或谨慎使用 Unicode 符号
4. **对比度达标**：WCAG AA 标准，正文 4.5:1，大标题 3:1
