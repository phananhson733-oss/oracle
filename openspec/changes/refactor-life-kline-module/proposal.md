# Change: 全面重构人生K线功能模块

## Why

当前「人生K线」功能过于简单，仅展示行星周期列表，缺乏：
1. **可视化K线图表**：没有真正的K线图展示，用户无法直观感受人生运势走势
2. **丰富的年度解读**：缺少四维评分（事业/财运/感情/健康）、月度运势、行动建议等深度内容
3. **商业化入口**：没有付费解锁机制，无法实现营收

参考用户提供的 React 原型设计，需要全面重构以提升产品价值和用户体验。

## What Changes

### 前端（微信小程序）

1. **新增 Canvas K线图组件**
   - 基于 Canvas 2D 绘制真实的K线蜡烛图
   - 支持 1-50岁 / 51-100岁 / 全部 三种视图范围
   - 标记重要节点（土星回归、木星回归、天王星对分相）
   - 标记当前年份

2. **新增年度详情弹窗**
   - 年度主题（如「土星回归·人生结构重建」）
   - K线数据（开/收/高/低）
   - 四维评分条（事业/财运/感情/健康）
   - 占星视角 + 八字视角摘要
   - 行动建议（必做/禁忌清单）
   - 月度运势表格
   - 个性化寄语

3. **新增完整报告视图**
   - 人生运势总览（免费）
   - 过去：命运回溯（免费）
   - 现在：当下定位（免费）
   - 未来30年运势详解（**付费**）
   - 人生里程碑预测（**付费**）
   - 给未来的你（**付费**）

4. **付费解锁机制**
   - 部分章节需付费解锁（¥29.9 一次性）
   - 订阅用户自动解锁全部内容

### 后端（Node.js）

1. **新增 K线数据生成 API**
   - `/api/kline/generate` - 生成100年K线数据
   - 基于真实占星周期（土星29.5年、木星12年、天王星42年对分）
   - 融合八字干支能量计算

2. **新增年度报告 AI 生成**
   - `/api/kline/year-report` - 生成指定年份的深度解读
   - 四维运势分析
   - 月度运势生成

3. **付费配置**
   - 新增 `KLINE_REPORT_UNLOCK` 价格配置
   - 集成 Stripe 支付

## Impact

- **Affected specs**: `life-kline`（新增能力）
- **Affected code**:
  - `miniprogram/pages/kline/` - 页面重构
  - `miniprogram/components/kline-chart/` - 新增K线图组件
  - `backend/src/api/kline.ts` - 新增API
  - `backend/src/services/kline.ts` - 新增K线数据服务
  - `backend/src/prompts/templates/kline/` - 新增/修改Prompt模板
  - `backend/src/config/stripe.ts` - 新增价格配置

## Out of Scope

- 不修改现有的周期列表 API（`/api/cycle/list`），新功能使用新 API
- 不修改其他页面的付费逻辑
- 暂不支持导出PDF报告功能
