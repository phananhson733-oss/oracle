# 提案：优化小程序星盘组件

## 背景

当前 AstroMind 微信小程序中的星盘组件（`astromind/miniprogram/components/astro-chart/`）功能基本完整，但视觉效果与 Web 版本（`components/AstroChart.tsx`）存在明显差距。用户提供的参考图展示了 Web 版本的优秀效果：

- **单盘（本命盘）**：完整的行星位置信息（符号 + 度数 + 星座 + 分 + 逆行标记）
- **双盘（行运盘）**：内外环清晰分离，跨盘相位线正确绘制

## 问题分析

### 现有小程序星盘的不足

1. **行星信息不完整**：仅显示行星符号，缺少度数、星座、角分、逆行标记
2. **宫头标注缺失**：未显示宫头的度数和星座信息
3. **布局比例不够精细**：与 Web 版本的专业布局存在差距
4. **字体渲染差异**：Canvas 2D 的文字渲染与 SVG 有差异

### Web 版本的优势特性

1. **完整的行星位置信息**：径向排列（符号 → 度数° → 星座符号 → 分' → 逆行标记）
2. **宫头标注**：沿星座环排布，格式为「度数 [星座icon] 分」
3. **防重叠算法**：`spreadPlanets()` 确保行星不重叠
4. **分层相位渲染**：前景/中景/背景三层，根据 orb 值分层
5. **连接线**：当行星位置偏移时显示虚线连接实际黄道位置

## 迁移挑战

### 技术差异

| 特性 | Web 版本 | 小程序版本 |
|------|----------|------------|
| 渲染技术 | SVG | Canvas 2D |
| 坐标系 | viewBox 400×400 | 动态尺寸 + DPR |
| 文字渲染 | `<text>` 元素 | `ctx.fillText()` |
| 路径绘制 | `<path>` 元素 | `Path2D` API |
| 交互 | DOM 事件 | Canvas 点击区域计算 |

### 尺寸适配

- Web 版本：最大 1280px，viewBox 400×400
- 小程序版本：通常 350px 左右，需等比例缩小
- 缩放比例：约 0.875（350/400）

### 微信小程序限制

1. **Canvas 2D API 限制**：部分高级 API 不可用
2. **字体支持**：Unicode 符号字体渲染可能不一致
3. **性能考虑**：复杂绘制可能影响滚动流畅度
4. **Path2D 兼容性**：需要检测并提供回退方案

## 解决方案

### 方案概述

将 Web 版本的核心绘制逻辑迁移到小程序，保持视觉一致性的同时适配小程序环境。

### 核心改动

1. **增强行星信息显示**
   - 添加度数、星座符号、角分、逆行标记
   - 实现径向排列布局
   - 添加偏移连接线

2. **添加宫头标注**
   - 在星座环上显示宫头信息
   - 格式：度数 + 星座符号 + 分

3. **优化布局参数**
   - 统一单盘/双盘的几何常量
   - 等比例缩放适配小尺寸

4. **改进相位线渲染**
   - 实现三层分层渲染
   - 优化颜色和透明度

### 不迁移的特性

- Hover tooltip（小程序使用点击详情卡片）
- 主题切换（小程序暂不支持深色模式）
- SVG 滤镜效果（Canvas 不支持）

## 影响范围

### 修改文件

1. `astromind/miniprogram/components/astro-chart/astro-chart.js` - 主绘制逻辑
2. `astromind/miniprogram/components/astro-chart/chart-utils.js` - 工具函数
3. `astromind/miniprogram/constants/chart-config.js` - 配置常量

### 受影响页面

1. `pages/self/` - 本我页面（本命盘）
2. `pages/daily/` - 今日运势页面（行运盘）
3. `pages/chart/` - 专业排盘页面
4. `pages/discovery/` - 发现页面（合盘）

## 验收标准

1. 单盘（本命盘）显示完整行星位置信息
2. 双盘（行运盘）内外环清晰分离
3. 宫头标注正确显示
4. 相位线分层渲染正确
5. 行星防重叠算法生效
6. 在不同尺寸下正确缩放
7. 点击交互正常工作

## 风险评估

| 风险 | 可能性 | 影响 | 缓解措施 |
|------|--------|------|----------|
| Canvas 性能问题 | 中 | 中 | 优化绘制逻辑，减少重绘 |
| 字体渲染不一致 | 中 | 低 | 使用 SVG Path 作为回退 |
| 小尺寸下信息过密 | 高 | 中 | 动态调整字号和间距 |
| Path2D 兼容性 | 低 | 中 | 检测并使用 Unicode 回退 |

## 时间线

1. **阶段一**：单盘优化（行星信息 + 宫头标注）
2. **阶段二**：双盘优化（内外环布局 + 跨盘相位）
3. **阶段三**：测试与调优（各页面验证 + 性能优化）
