# 星盘显示配置 - 小程序优化增量

## MODIFIED Requirements

### Requirement: 小程序星盘组件显示完整行星位置信息

小程序星盘组件 **SHALL** 显示与 Web 版本一致的完整行星位置信息，包括行星符号、度数、星座符号、角分和逆行标记。

#### Scenario: 单盘（本命盘）显示完整行星信息

**Given** 用户在「本我」页面查看本命星盘
**When** 星盘组件渲染完成
**Then** 每个行星应显示以下信息（从外到内径向排列）：
  - 行星符号（使用 Unicode 字符或 SVG Path）
  - 度数（如 "15°"）
  - 星座符号（使用 Unicode 字符）
  - 角分（如 "23'"）
  - 逆行标记（如 "R"，仅逆行时显示）
**And** 当行星位置有偏移时，应显示虚线连接实际黄道位置

#### Scenario: 双盘（行运盘）显示内外环行星信息

**Given** 用户在「今日运势」页面查看行运星盘
**When** 星盘组件渲染完成
**Then** 外环（行运行星）应显示完整位置信息（字号缩放 90%）
**And** 内环（本命行星）应显示完整位置信息（字号缩放 90%）
**And** 内外环之间应有清晰的分隔线

### Requirement: 小程序星盘组件显示宫头标注

小程序星盘组件 **SHALL** 在星座环上显示宫头标注信息。

#### Scenario: 显示 12 个宫头标注

**Given** 用户查看任意类型的星盘
**When** 星盘组件渲染完成
**Then** 星座环上应显示 12 个宫头标注
**And** 每个宫头标注应包含：度数 + 星座符号 + 分
**And** 标注位置应与宫位线对齐
**And** 文字方向应根据角度自动调整（保持可读性）

### Requirement: 小程序星盘组件支持行星点击详情

小程序星盘组件 **SHALL** 支持点击行星显示详情卡片，功能对标 Web 版本的悬停提示。

#### Scenario: 点击行星显示详情卡片

**Given** 用户查看星盘
**When** 用户点击某个行星
**Then** 应显示详情卡片，包含：
  - 行星符号和名称
  - 逆行/顺行状态
  - 星座位置（星座名 + 符号 + 度数）
  - 宫位信息（所在宫位 + 守护宫位）
  - 相关相位列表（最多 5 个，按 orb 排序）
**And** 卡片位置应自适应，避免超出屏幕边界

#### Scenario: 点击空白处关闭详情卡片

**Given** 详情卡片正在显示
**When** 用户点击星盘空白区域
**Then** 详情卡片应关闭

#### Scenario: 双盘显示跨盘相位

**Given** 用户在行运盘或对比盘中点击行星
**When** 详情卡片显示相位列表
**Then** 跨盘相位应优先显示
**And** 相位应标注是否为跨盘相位

### Requirement: 小程序星盘组件相位线分层渲染

小程序星盘组件 **SHALL** 实现相位线分层渲染，与 Web 版本一致。

#### Scenario: 相位线按 orb 值分层显示

**Given** 用户查看星盘
**When** 星盘组件渲染相位线
**Then** 相位线应按 orb 值分为三层：
  - 前景层（orb ≤ 2°）：最亮，线宽 1.8px，透明度 1.0
  - 中景层（2° < orb ≤ 4°）：中等，线宽 1.2px，透明度 0.8
  - 背景层（orb > 4°）：最暗，线宽 0.8px，透明度 0.5
**And** 绘制顺序应为：背景 → 中景 → 前景
