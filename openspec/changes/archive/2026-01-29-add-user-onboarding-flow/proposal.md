# 提案：新用户信息收集引导流程

## 背景

AstroMind 是一款面向中国大陆年轻人的占星应用，核心功能（本命盘、日运、问答等）都需要用户的出生信息。当前用户登录后没有引导流程，使用的是默认出生信息，导致用户无法获得个性化的占星体验。

## 目标

为新用户提供简洁高效的出生信息收集流程，确保：
1. 快速引导：仅两步完成（出生时间 + 出生地点）
2. 用户友好：支持不确定出生时间的场景，支持阳历/农历切换
3. 专业可信：展示 Swiss Ephemeris 和 NASA JPL 数据库计算精度说明
4. 数据复用：收集的信息持久化后供所有需要用户资料的功能使用

## 功能范围

### 核心功能

1. **新用户引导页面** (`/pages/onboarding/onboarding`)
   - 步骤一：出生日期与时间
     - 日期选择器（默认阳历，支持切换农历）
     - 时间选择器（小时:分钟）
     - 「不确定具体时间」勾选框（勾选后默认 12:00）
     - 备注文案：「请填写阳历/公历日期，如选择农历将自动转换」
   - 步骤二：出生地点
     - 城市输入框，支持模糊搜索（汉字、拼音、拼音首字母）
     - 下拉候选列表展示匹配城市
     - 自动填充经纬度和时区
   - 底部信任标识：「基于 Swiss Ephemeris 瑞士星历表和 NASA JPL 数据库精密计算」

2. **农历转公历能力**（后端）
   - 新增 API 接口或集成农历转换库
   - 前端传入农历日期，后端返回对应公历日期
   - 用户无需感知转换过程

3. **用户资料编辑入口**
   - 在「我的」页面增加「编辑资料」入口
   - 复用引导页面组件，支持修改已保存的出生信息

4. **登录后跳转逻辑**
   - 新用户登录成功后自动跳转至引导页面
   - 已完成引导的用户跳过，直接进入首页
   - 通过 `user_profile.onboardingCompleted` 标识判断

### 数据结构扩展

扩展 `user_profile` 存储结构：
```javascript
{
  name: string,           // 昵称
  birthDate: string,      // 公历出生日期 YYYY-MM-DD
  birthTime: string,      // 出生时间 HH:mm
  birthCity: string,      // 出生城市显示名
  timezone: string,       // 时区
  lat: number,            // 纬度
  lon: number,            // 经度
  accuracyLevel: string,  // 'exact' | 'approximate'（是否确定时间）
  calendarType: string,   // 'solar' | 'lunar'（用户选择的日历类型，仅用于展示）
  onboardingCompleted: boolean  // 是否完成引导
}
```

## 不在范围内

- 用户注册/登录流程改造
- 出生证明验证
- 多用户资料管理
- 国际城市搜索（当前已有基础支持）

## 技术方案

### 前端

1. 新建 `/pages/onboarding/` 页面
2. 复用已有的 `city-search.js` 城市搜索工具
3. 使用微信小程序原生 picker 组件实现日期时间选择
4. 农历选择时调用后端转换接口

### 后端

1. 新增农历转公历 API：`POST /api/calendar/lunar-to-solar`
2. 可使用 `lunar-javascript` 或 `chinese-lunar-calendar` npm 包
3. 转换逻辑仅在后端执行，前端不需要引入农历库

### 用户体验流程

```
用户微信登录成功
    ↓
检查 onboardingCompleted
    ↓
false → 跳转 /pages/onboarding
    ↓
步骤1：填写出生日期时间
    ↓
步骤2：填写出生地点
    ↓
保存 user_profile（onboardingCompleted = true）
    ↓
跳转首页或目标页面
```

## 成功指标

1. 新用户引导完成率 > 80%
2. 平均引导时长 < 60 秒
3. 用户资料完整率（含出生信息）> 90%

## 风险与缓解

| 风险 | 缓解措施 |
|------|----------|
| 用户不知道自己的出生时间 | 提供「不确定具体时间」选项，默认 12:00 |
| 用户只知道农历日期 | 支持农历选择并自动转换 |
| 城市搜索无法匹配 | 城市库已覆盖中国所有地级市，支持多种搜索方式 |
| 用户中途放弃 | 简化为两步流程，减少填写负担 |

## 依赖

- 已有：`city-search.js` 城市搜索工具
- 已有：`cities.js` 城市数据库
- 需新增：农历转换 npm 包（后端）
