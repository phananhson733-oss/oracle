# Proposal: 将 CBT 日记本土化为「情绪日记」

## 问题

当前 CBT 日记模块存在明显的「欧美心理学工具直译」问题，与 AstroMind 面向中国年轻用户的定位不符：

1. **术语障碍**：「自动思维」「热点想法 (Hot Thought)」「认知重构」「庭审辩论」等 CBT 专业术语对普通用户不友好，增加理解成本
2. **流程僵化**：严格的 5 步 CBT 结构化流程（情境→情绪→想法→证据→平衡）过于教科书化，缺乏情感温度
3. **情绪选项单薄**：仅 4 种情绪（愉悦/平静/烦躁/糟糕），无法覆盖中国年轻人日常丰富的情绪光谱
4. **文化断裂**：整体设计更像翻译过来的欧美心理健康 App，未融入中国文化元素和表达习惯
5. **Prompt 术语化**：后端 AI 分析 Prompt 使用 CBT 专业框架输出，用户需要的是「有温度的洞察」而非「临床报告」

## 目标

将 CBT 日记重塑为「情绪日记」，保留认知行为疗法的科学内核，但用中国年轻人熟悉的语言和交互方式包装：

- 让用户感觉在「和懂自己的朋友聊天」，而非「做心理测评」
- 融入中国文化意象（节气、传统情绪词汇、诗词意境）
- 降低使用门槛，先吸引用户坚持记录，再逐步深化觉察

## 变更范围

### 1. 前端交互重塑（miniprogram/pages/cbt/）

**情绪选择重设计**：
- 扩展至 8-12 种情绪，使用中文情绪词汇（如：释然、委屈、焦虑、感动、无力、期待、孤独、满足）
- 每种情绪配以一个意境化的描述短语
- 支持多情绪复选（「又委屈又生气」是常见场景）

**引导流程本土化**：
| 旧步骤 | 新步骤 | 变化 |
|--------|--------|------|
| 情境：此刻发生了什么？ | 今天遇到了什么事？ | 更口语化 |
| 情绪标记 | 现在心里是什么感觉？ | 直觉优先 |
| 捕捉自动思维 + Hot Thought | 脑子里第一个蹦出来的念头是什么？ | 去术语化，合并为一步 |
| 辩论证据（支持/反驳） | 换个角度想想呢？ | 引导式提问替代「庭审」隐喻 |
| 平衡后的新视角 | 如果安慰最好的朋友，你会怎么说？ | 共情引导 |

**Dashboard 优化**：
- 日历保持，情绪点显示不同颜色
- 历史记录展示优化，支持按情绪类型筛选
- 添加「本月情绪小结」卡片（月末自动生成）

### 2. 后端 Prompt 本土化（backend/src/prompts/templates/cbt/）

**analysis.ts 改造重点**：
- AI 角色从「认知行为治疗师」→「懂你的朋友，碰巧也懂点心理学和占星」
- 输出格式从临床结构（cognitive_analysis/patterns）→ 自然语言段落
- 融入星象解读时用生活化比喻（「水星逆行就像手机信号不好，容易误会是正常的」）
- 思维模式用大白话命名（「灾难化」→「把小事想成世界末日」已有，需全面推广）

**新增 Prompt 能力**：
- 月度情绪回顾 Prompt（整合当月记录，生成温暖的回顾短文）
- 情绪关联星象 Prompt（简短解释当前行运为什么容易触发某种情绪）

### 3. 数据结构调整（backend/src/api/cbt.ts）

- `CBTRecord` 接口适配新的多情绪选择
- `moods` 字段从单选扩展为多选数组
- 新增 `bodySignal` 字段（身体感受，可选）
- 分析 API 响应格式从 JSON 结构化数据改为 Markdown 文本

## 不变更

- 后端 API 路由结构（`/api/cbt/*`）保持不变
- Redis 缓存策略和 3 个月 TTL 保持不变
- 安全边界（`CBT_SAFETY`）保持不变
- 6 个分析端点保持不变（仅修改 Prompt 内容）

## 风险

- **数据兼容**：旧格式的 CBT 记录需要在前端做兼容读取
- **AI 输出不确定性**：Prompt 从结构化 JSON 改为自然语言后，前端渲染需适配
